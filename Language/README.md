# Jyuno Language

Jyuno 에서는 한 줄에 하나의 명령어만 실행할수 있는것이 원칙입니다.

``//``부터 줄 끝까지는 주석입니다. (1.6.0부터, 문자열 안의 ``//``는 제외)
```
// 주석
x = 1 + 2 // 줄 끝 주석
```

## 상수(Constant)
Jyuno에서 의미하는 상수는, 변수가 아닌 고정된 값 그자체를 의미합니다.<br>
614, "Jyunni", true, null 등 이와 같은 값을 상수라고 정의합니다.<br>
### 숫자
#### 정수
정수는 단순히 숫자를 표기하면 됩니다. (예: ``6145020``)  
음수는 숫자 바로 앞에 ``-``를 붙이면 됩니다. (예: ``-614``)  
단, ``a-1``이나 ``(x)-1``처럼 값 바로 뒤에 붙어 있는 ``-``는 [뺄셈 연산자](#연산자-160부터)입니다. (1.6.0부터)  
C# 기준으로 long 범위(``-9223372036854775808`` ~ ``9223372036854775807``)를 넘는 정수를 적으면 문법 오류가 발생합니다.  
허나 계산 결과가 long 범위를 넘어갈 경우 오버플로우/언더플로우가 된다는 점을 주의하세요.
#### 유한소수
유한소수도 (정수).(소수) 형식으로 표기하면 됩니다. (예: ``6.14``, ``-0.5``)  
기본적으로 double 자료형으로 저장합니다.

### 문자열
문자열은 큰/작은 따옴표로 문자열 양쪽을 감싸면 됩니다. (예: ``'614project'``)  
큰 따옴표나 작은 따옴표 둘중 편한대로 사용하면 됩니다, 하지만 양쪽 따옴표가 모두 동일해야합니다.  
잘못된 예:
- ``"jyunni'``
- ``'Jyuno"``

올바른 예:
- ``'jyunrcaea'``
- ``"hello world!"``

문자열 내에서 따옴표를 표시하는 방법은 역슬래시(``\``) 기호를 사용하면 됩니다. (예: ``'I am \'Jyunni\'.'``)  
역슬래시 기호가 있을경우 역슬래시 다음 문자를 그대로 포함합니다. (예: ``'backslash: \\, single quote: \', double quotes: \"'``)  
허나 다음 문자가 'n'인경우 줄바꿈으로 변한되어 포함됩니다. (예: ``"first line\nsecond line"``)

### 불리언(논리형)
참은 ``true``, 거짓은 ``false`` 로 표기하면 됩니다.  

### null (= void)
null은 문자 그대로 ``null``로 표기하면 됩니다.

Jyuno에서 재밌는 사실은 void 대신 null을 사용합니다.  
그렇기에 console.write 같은 반환할 값이 없는 함수들은 모두 null을 반환합니다. 

## 변수(Variable)
Jyuno에서의 변수는 Python과 Javascript의 그 사이 어딘가입니다.<br>
Jyuno 변수의 특징은 아래와 같습니다.
- 동적 타입
- 타입에 관대함 (1 + '2' = '12')
- 삭제 가능 (곧 후술함)
### 선언/대입
변수의 선언/대입은 다음과 같습니다.
```
(변수명) = (값)
```
Jyuno 변수는 별다른 선언 과정 없이, 존재하지 않던 변수에 값을 대입할려고 하면, 그 즉시 선언됩니다.
### 삭제
변수의 삭제는 다음과 같이 이름 뒤에 등호만 붙히면 끝입니다.
```
(변수명) =
```
여기서 Python의 del과 차이점은, 없는 변수를 삭제할려고 해도 오류가 발생하지 않습니다.<br>
만약 삭제가 성공할경우 True를 반환하고, 그렇지 않으면 False를 반환합니다.
### 상수
상수를 선선하는 방법은 다음과 같습니다. (~~변수를 뒤집으면? 상수~~)
```
(상수값) = (변수명)
```
해당 변수가 이미 존재하는지의 여부와 상관없이 상수로 선언되며, 대입 연산이 금지됩니다. (다른 상수값을 대입할수는 있습니다.)
## 함수(Function)
### 호출하기
함수는 아래와 같은 유형으로 실행할수 있습니다.
```
(함수명) (인자1) (인자2) ...
```
왼쪽에 함수 이름을 입력하고, 그 뒤에 함수에 넣을 인자를 차례대로 넣어주면 됩니다!<br>
예: ``console.write "hello {1}" "world!"``
<br><br>
그리고 함수에서 반환된 값을 저장할수도 있습니다.
```
(변수) = (함수명) (인자1) (인자2) ...
```
예: ``a = add 10 20``
### 삭제하기
Jyuno에서 함수는 변수로 취급하기 때문에, 삭제가 가능합니다.
```
(함수명) =
```
단, 프로그램(런타임)이 제공하는 함수/변수는 해당 스크립트에서만 삭제되며, 다른 스크립트에는 영향을 주지 않습니다.
### 반환값을 인자로 사용하기
Jyuno에서는 괄호를 통해 다음과 같은 방법으로 함수를 실행해서 나온 값을 다시 다른 함수에 넘겨 쓸수 있습니다.
```
console.write (add "hello! " (console.readline))
```
괄호 내에서는 똑같이 ``(함수명) (인자1) (인자2)...`` 규칙이 적용됩니다. 별개의 명령줄로 생각하면 편합니다.
## 조건문
### if
Jyuno에서의 if문은 아래와 같은 형식을 가집니다. (들여쓰기는 필수가 아닙니다.)
```
if (값)
   (실행할 코드)
end
```
(값)이 null, false, 0이 아닌 경우 true로 판단되며 if와 end 사이의 코드가 실행되고,  
그렇지 않은경우 false로 판단되며 end까지 건너뜁니다.
### else
Jyuno에서의 else는 아래와 같은 형식을 가집니다.
```
if (값)
   (값이 참일때 실행할 코드)
else
   (값이 거짓일때 실행할 코드)
end
```
(값)이 false로 판단되는 경우, else와 end사이의 코드가 실행됩니다.
### while
Jyuno에서의 while은 아래와 같은 형식을 가집니다.
```
while (값)
	(값이 참일동안 실행될 코드)
end
```
(값)이 true로 판단되는 동안 while와 end 사이의 코드가 반복하여 실행됩니다.
### repeat
Jyuno에서 repeat은 아래와 같은 형식을 가집니다.
```
repeat (값:정수)
	(값 횟수만큼 반복할 코드)
end
```
정수인 (값)의 횟수만큼 repeat와 end 사이의 코드가 실행됩니다.
### for
Jyuno에서 for는 아래와 같은 형식을 가집니다.
```
for (변수명) (값:배열|리스트|문자열)
	(원소마다 실행할 코드)
end
```
(값)의 원소를 처음부터 차례대로 (변수명)에 넣고, for와 end 사이의 코드를 원소 개수만큼 실행합니다. 문자열은 한 글자씩 문자열로 순회합니다.
```
sum = 0
for x (array 1 2 3)
	sum = add sum x
end
console.writeline sum
```
위 코드는 ``6``을 출력합니다.

for와 end 사이는 반복 한번마다 새로 만들어지는 하위 영역에서 실행됩니다.  
(변수명)과 for 안에서 처음 만든 변수는 그 반복에서만 쓰이는 지역 변수이며, for가 끝나면 사라집니다. (바깥에 같은 이름의 변수가 있어도 바뀌지 않습니다.)  
함수 안처럼 for 밖에 이미 있는 변수에 대입하면 그 변수가 바뀝니다.  
(값)은 for를 시작할때 한번만 읽으며, 반복 도중에 배열/리스트를 바꿔도 순회할 원소는 바뀌지 않습니다.
### break
Jyuno에서 break는 가장 안쪽 반복문의 end까지 코드 실행을 건너뛰고, 반복문을 빠져나옵니다.  
모든 반복문에서 사용할수 있으며, 반복문 안의 if 안에서도 사용할수 있습니다.
### goto
Jyuno에서 goto는 아래와 같은 형식을 가집니다.
```
goto (값:정수)
```
(값)번째 줄(첫 줄은 0)부터 이어서 실행합니다.  
줄 번호 대신 레이블을 사용할수도 있습니다. ``(이름):`` 형식으로 레이블을 만들면, 그 줄의 번호가 변수에 저장됩니다.
```
count = 3
loop:
console.writeline count
count = sub count 1
if count
	goto loop
end
```
단, goto로 함수 안팎을 넘나들수는 없습니다.
## 함수 만들기
### func
Jyuno에서 함수는 아래와 같은 형식으로 만듭니다.
```
func (함수명)
	param (첫번째 파라미터 이름)
	param (두번째 파라미터 이름)
	(코드)
	param (세번째 파라미터 이름)
endfunc
```
``func``를 만나면 함수가 만들어지기만 하고, 본문은 함수를 호출할 때 실행됩니다. (따라서 함수는 호출하기 전에 먼저 만들어야 합니다.)  
만든 함수는 다른 함수처럼 ``(함수명) (인자1) (인자2) ...``로 호출합니다.
### param
``param``은 함수 본문 안에서 쓴 순서대로 첫번째, 두번째, ... 인자를 받습니다. 코드 중간에 있어도 되며, 그 줄이 실행될때 변수가 만들어집니다.  
인자가 부족하게 들어오면 남은 파라미터는 모두 ``null``이 되고, 인자가 더 많이 들어오면 남는 인자는 무시됩니다.
### 반환
``return (값)``으로 값을 반환합니다. ``return`` 없이 ``endfunc``에 도달하면 ``null``을 반환합니다.
```
func fact
	param n
	if (equal n 0)
		return 1
	end
	return (mul n (fact (sub n 1)))
endfunc
console.writeline (fact 5)
```
재귀 호출도 가능하지만, 최대 200번까지만 중첩해서 호출할수 있습니다.
### 지역 변수
함수 안에서 처음 만든 변수(파라미터, 레이블, 함수 안에서 만든 함수 포함)는 그 호출만의 지역 변수이며, 함수가 끝나면 사라집니다.  
재귀 호출을 해도 호출마다 지역 변수가 따로 있으므로, 안쪽 호출이 바깥 호출의 변수를 바꾸지 않습니다.
```
func countdown
	param n
	x = n
	if n
		countdown (sub n 1)
	end
	console.writeline x
endfunc
countdown 2
```
위 코드는 ``0``, ``1``, ``2`` 순서로 출력합니다.

함수 밖의 변수는 읽거나 바꿀수 있습니다. 이미 있는 변수에 대입하면 그 변수가 바뀌고, 없는 변수에 대입해야 지역 변수가 새로 만들어집니다.
```
total = 0
func add_score
	param score
	total = add total score
endfunc
add_score 10
add_score 20
console.writeline total
```
위 코드는 ``30``을 출력합니다.

여기서 "함수 밖"은 함수를 만든 곳(스크립트 최상위, 또는 함수를 감싸는 함수)을 뜻합니다.  
함수를 호출한 다른 함수의 지역 변수는 보이지 않으며, 읽거나 바꿀수 없습니다. (파라미터는 항상 지역 변수입니다.)
### local
함수 밖에 같은 이름의 변수가 있더라도 함수 안에서만 쓰는 변수가 필요하다면, ``local``로 지역 변수를 선언합니다.
```
local (변수명) = (값)
local (변수명)
```
``local``로 선언한 변수는 바깥 변수를 가리고 지금 함수 호출의 지역 변수가 되며, 이후 그 이름에 대입하면 지역 변수가 바뀝니다. 값을 생략하면 ``null``이 됩니다.
```
i = 'outside'
func f
	local i = 0
	repeat 3
		i = add i 1
	end
	console.writeline i
endfunc
f
console.writeline i
```
위 코드는 ``3``, ``outside`` 순서로 출력합니다.  
함수 밖(스크립트 최상위)에서 ``local``을 쓰면 일반 대입과 같습니다.
## 구조체(struct)
1.5.0부터 여러 값(필드)과 그 값을 다루는 함수(구조체 함수)를 하나로 묶은 구조체를 만들수 있습니다.
### 만들기
```
struct person
	param name
	param rating
	func show
		console.write "{1} rating is {2}" name rating
	endfunc
endstruct
```
``struct``와 ``endstruct`` 사이는 사실상 생성자입니다. ``struct``를 만나면 구조체가 만들어지기만 하고, 본문은 구조체 값을 만들 때(구조체를 호출할 때) 실행됩니다.  
본문의 ``param``은 함수처럼 쓴 순서대로 인자를 받으며, 본문에서 만든 변수(``param`` 포함)는 **필드**, 본문에서 만든 함수는 **구조체 함수**가 됩니다.  
본문에 다른 코드(대입, ``if``, ``for`` 등)를 써도 되며, ``return``은 생성자를 끝내기만 합니다. (반환한 값은 무시)
### 구조체 값 만들기
구조체는 함수처럼 호출해서 구조체 값을 만듭니다.
```
me = person "Jyunni" 2424
me.show
```
위 코드는 ``Jyunni rating is 2424``를 출력합니다.

구조체 값을 변수(``me``)에 넣으면, 같은 영역에 ``(변수명).(필드)``와 ``(변수명).(구조체 함수)`` 이름이 함께 선언됩니다. (``me.name``, ``me.rating``, ``me.show``)  
이미 같은 이름(예: 직접 만든 ``me.show`` 함수)이 있다면 덮어씁니다. 변수에 다른 값을 대입하거나 변수를 삭제하면, 그 변수 때문에 선언된 이름도 사라집니다.
```
console.writeline me.name
me.rating = 2525
me.show
```
``me.name``처럼 필드를 읽고 쓸수 있으며, 구조체 함수 안에서는 필드를 이름 그대로(``name``, ``rating``) 읽고 바꿀수 있습니다.  
구조체 함수 안에서 처음 만든 변수는 함수처럼 그 호출의 지역 변수입니다. 구조체 함수는 구조체를 만든 곳의 변수도 읽거나 바꿀수 있습니다.
### 복사 (깊은 복사)
구조체 값은 복사해서 전달됩니다. 다른 변수에 대입하거나, 함수의 인자로 넘기거나, 반환하거나, 배열/리스트에 넣을 때 모두 새로 복사되므로 원래 구조체 값은 바뀌지 않습니다.  
복사는 **깊은 복사**이므로, 필드에 있는 구조체 값과 배열/리스트도 모두 복사됩니다.
```
a = person "Jyunni" 2424
b = a
b.rating = 0
a.show
b.show
```
위 코드는 ``Jyunni rating is 2424``, ``Jyunni rating is 0`` 순서로 출력합니다.

필드에 구조체 값이 있다면 ``l.from.x``처럼 이어서 이름이 선언됩니다.  
``equal``은 같은 구조체이고 모든 필드의 값이 같다면 ``true``입니다. (배열/리스트 필드는 원소끼리 비교) ``string``으로 바꾸면 ``person { name = Jyunni, rating = 2424 }`` 형식의 문자열이 됩니다.
## 배열/리스트
### 만들기
``array``는 배열(C#의 ``T[]``)을, ``list``는 리스트(C#의 ``List<T>``)를 만듭니다. 인자로 넣은 값들이 차례대로 원소가 됩니다.
```
a = array 1 2 3
l = list 'jyunni' 'jyuno'
```
모든 원소가 같은 타입(정수, 실수, 문자열, 논리형)이라면 그 타입의 컬렉션이 됩니다. (예: ``array 1 2 3``은 ``long[]``, ``list 'a' 'b'``는 ``List<string>``)  
타입이 섞여 있거나, ``null``이 있거나, 원소가 없다면 아무 값이나 넣을수 있는 ``object[]``/``List<object>``가 됩니다.

배열은 길이를 바꿀수 없고, 리스트는 C# 프로그램이 원소를 추가/삭제할수 있다는 점이 다릅니다.  
C# 프로그램이 제공한 배열이나 리스트(``IList``를 구현한 값)도 똑같이 사용할수 있습니다.
### 읽기/쓰기
배열/리스트가 담긴 변수 뒤에 인덱스(첫 원소는 0)를 쓰면 원소를 읽고, 인덱스 뒤에 값을 쓰면 그 원소를 바꿉니다.
```
(변수명) (인덱스)
(변수명) (인덱스) (값)
```
예를 들어 ``l 0 (l 1)``은 C 계열 언어의 ``l[0] = l[1]``과 같습니다.
```
l = array 10 20 30
l 0 (l 2)
console.writeline (l 0)
```
위 코드는 ``30``을 출력합니다.  
인덱스는 정수여야 하며, 범위를 벗어나면 오류가 발생합니다. 원소 타입에 맞지 않는 값(예: ``long[]``에 문자열)을 넣어도 오류가 발생합니다. (정수를 실수 배열에 넣는 것처럼 숫자끼리는 자동으로 변환됩니다.)  
배열/리스트는 참조로 전달되므로, 함수에 넘긴 배열의 원소를 함수 안에서 바꾸면 바깥에서도 바뀝니다.
### 길이와 순회
``length``로 배열/리스트의 원소 개수(문자열이라면 글자 수)를 구할수 있고, ``for``로 원소를 차례대로 순회할수 있습니다.
```
l = array 1 2 3
console.writeline (length l)
for x l
	console.writeline x
end
```
### 합치기 (add)
``add``의 첫 인자가 배열/리스트라면, 두번째 인자부터의 값들을 뒤에 이어붙인 새 배열/리스트를 반환합니다.  
인자가 배열/리스트라면 한 단계만 펼쳐서 원소들을 이어붙이고, 그 외의 값은 원소 하나로 이어붙입니다.
```
add (array 1 2) (array 3 4) (array 5 6)
```
위 코드는 ``array 1 2 3 4 5 6``과 같습니다. ``add (array 1) (array 2 (array 3))``처럼 배열 안의 배열은 펼치지 않으므로 결과는 ``[1, 2, [3]]``이 됩니다.
### 빼기 (sub)
``sub``의 첫 인자가 배열/리스트라면, 두번째 인자에 있는 원소와 같은 원소를 모두 제거한 새 배열/리스트를 반환합니다. (집합의 차집합 ``A - B``)  
두번째 인자가 배열/리스트가 아니라면 그 값 하나와 같은 원소를 모두 제거합니다. 원소는 ``equal``과 같은 기준으로 비교합니다. (``1``과 ``1.0``은 같음)
```
sub (array 1 2 3 2 4) (array 2 4)
```
위 코드는 ``array 1 3``과 같습니다.

``add``와 ``sub``는 원래 배열/리스트를 바꾸지 않습니다. 결과는 첫 인자와 같은 종류(배열 또는 리스트)이며, 결과 원소가 모두 들어갈수 있다면 첫 인자와 같은 원소 타입을 유지합니다.
### 문자열 나누기 (div)
``div``의 첫 인자가 문자열이라면, 두번째 인자를 구분자로 문자열을 나눈 문자열 배열을 반환합니다. (C#의 ``a.Split(b)``)
```
words = div 'hello jyuno world' ' '
console.writeline (words 1)
```
위 코드는 ``jyuno``를 출력합니다.
### 컬렉션 함수 (array.\*, list.\*)
배열/리스트를 다루는 함수입니다. (1.4.1부터)  
``array.sort``와 ``list.sort``처럼 이름이 같은 함수는 똑같이 동작하며, 배열과 리스트를 모두 받을수 있습니다.  
길이를 바꾸는 함수(``list.push``, ``list.pop`` 등)는 ``list``에만 있으며, 배열에 쓰면 오류가 발생합니다.

| 함수 | 설명 |
|---|---|
| ``array.sort (컬렉션)`` / ``array.sort (컬렉션) true`` | 오름차순으로 정렬합니다. 두번째 인자가 참이라면 내림차순으로 정렬합니다. |
| ``array.reverse (컬렉션)`` | 순서를 뒤집습니다. |
| ``array.shuffle (컬렉션)`` | 순서를 무작위로 섞습니다. |
| ``array.contains (컬렉션) (값)`` | 값과 같은 원소가 있다면 ``true``를 반환합니다. |
| ``array.indexof (컬렉션) (값)`` | 값과 같은 첫 원소의 인덱스를 반환합니다. 없다면 ``-1``을 반환합니다. |
| ``array.slice (컬렉션) (시작)`` / ``array.slice (컬렉션) (시작) (끝)`` | 시작 인덱스부터 끝 인덱스 바로 앞까지(끝을 생략하면 마지막까지)의 원소로 새 배열/리스트를 만듭니다. |
| ``array.join (컬렉션)`` / ``array.join (컬렉션) (구분자)`` | 원소를 문자열로 바꿔서 구분자(생략하면 빈 문자열)로 이어붙인 문자열을 반환합니다. ``null``은 빈 문자열이 됩니다. |
| ``array.new (길이)`` / ``array.new (길이) (값)`` | 모든 원소가 값(생략하면 ``null``)인 배열을 만듭니다. ``list.new``는 리스트를 만듭니다. |
| ``array.copy (컬렉션)`` | 같은 종류, 같은 원소 타입의 새 배열/리스트로 복사합니다. (원소 자체는 복사하지 않는 얕은 복사, 1.4.2부터) |
| ``array.lastindexof (컬렉션) (값)`` | 값과 같은 마지막 원소의 인덱스를 반환합니다. 없다면 ``-1``을 반환합니다. (1.4.2부터) |
| ``array.count (컬렉션) (값)`` | 값과 같은 원소의 개수를 반환합니다. (1.4.2부터) |
| ``array.distinct (컬렉션)`` | 중복된 원소를 제거한 새 배열/리스트를 반환합니다. 같은 값이 여러개라면 처음 나온 원소를 남깁니다. (1.4.2부터) |
| ``array.binary_search (컬렉션) (값)`` | 오름차순으로 정렬된 배열/리스트에서 값을 이진 탐색합니다. 찾았다면 그 인덱스(같은 값이 여러개라면 가장 앞)를, 없다면 값이 들어갈 위치를 ``not``으로 반전한 음수를 반환합니다. (C#의 ``Array.BinarySearch``, 1.4.2부터) |
| ``array.fill (컬렉션) (값)`` | 모든 원소를 값으로 바꿉니다. (1.4.2부터) |
| ``array.min (컬렉션)`` / ``array.max (컬렉션)`` | 가장 작은/큰 원소를 반환합니다. 같은 값이 여러개라면 앞의 원소를 반환하며, 빈 배열/리스트라면 오류가 발생합니다. (1.4.2부터) |
| ``array.sum (컬렉션)`` | 모든 원소(숫자)를 ``add``와 같이 더한 값을 반환합니다. 빈 배열/리스트라면 ``0``입니다. (1.4.2부터) |
| ``array.range (끝)`` / ``array.range (시작) (끝)`` / ``array.range (시작) (끝) (간격)`` | 시작(생략하면 0)부터 끝 바로 앞까지 간격(생략하면 1)만큼 커지는 정수 배열을 만듭니다. 간격이 음수라면 작아집니다. ``list.range``는 리스트를 만듭니다. (1.4.2부터) |
| ``list.push (리스트) (값) (값) ...`` | 리스트 끝에 값들을 추가합니다. |
| ``list.pop (리스트)`` | 마지막 원소를 제거하고, 그 원소를 반환합니다. |
| ``list.insert (리스트) (인덱스) (값)`` | 인덱스 위치에 값을 끼워넣습니다. (인덱스가 길이와 같다면 끝에 추가) |
| ``list.removeat (리스트) (인덱스)`` | 인덱스 위치의 원소를 제거하고, 그 원소를 반환합니다. |
| ``list.remove (리스트) (값)`` | 값과 같은 첫 원소를 제거합니다. 제거했다면 ``true``, 없다면 ``false``를 반환합니다. |
| ``list.clear (리스트)`` | 모든 원소를 제거합니다. |

``sort``, ``reverse``, ``shuffle``, ``fill``, ``push``, ``insert``, ``clear``는 새 배열/리스트를 만들지 않고 **원래 배열/리스트를 바꾸며**, 바꾼 배열/리스트를 그대로 반환합니다.  
원래 배열/리스트를 그대로 두고 싶다면 ``array.slice (컬렉션) 0``으로 복사한 뒤에 사용하세요. (``slice``, ``copy``, ``distinct``는 항상 새 배열/리스트를 만듭니다.) 1.4.2부터는 ``array.copy``로 복사할수도 있습니다.
```
scores = list 70 95 80
list.push scores 60
array.sort scores true
console.writeline (list.join scores ', ')
```
위 코드는 ``95, 80, 70, 60``을 출력합니다.

정렬(``sort``, ``binary_search``, ``min``, ``max``)은 ``less``/``greater``와 같은 기준(숫자는 값, 문자열은 유니코드 순서)으로 비교하며, 같은 값끼리는 내림차순이더라도 원래 순서를 유지합니다. (안정 정렬)  
숫자와 문자열, ``null``처럼 크기를 비교할수 없는 값이 섞여 있다면 오류가 발생합니다. ``math.nan``은 오름차순이라면 가장 앞에, 내림차순이라면 가장 뒤에 둡니다.  
``contains``, ``indexof``, ``lastindexof``, ``count``, ``distinct``, ``remove``는 ``equal``과 같은 기준으로 비교합니다. (``1``과 ``1.0``은 같음)  
``list.push``, ``list.insert``로 넣는 값이 리스트의 원소 타입에 맞지 않으면(예: ``list 1 2``로 만든 정수 리스트에 문자열) 오류가 발생합니다. 아무 값이나 넣고 싶다면 ``list``(빈 리스트)로 만드세요.
## 문자열 함수 (string.\*)
C#의 ``System.String`` 메서드를 옮긴 함수입니다. (1.4.2부터)  
문자열을 받는 자리에 다른 타입의 값을 넣으면 오류가 발생합니다. (``string.concat``, ``string.join``, ``string.format``은 모든 값을 문자열로 바꿉니다.)  
문자열을 찾고 비교하는 함수는 모두 유니코드 값(서수, C#의 ``StringComparison.Ordinal``) 기준이므로 대소문자를 구별하며, 대소문자 변환은 문화권과 무관합니다. (C#의 ``ToUpperInvariant``)  
인덱스는 첫 글자가 0이며, 범위를 벗어나면 오류가 발생합니다.

| 함수 | 설명 |
|---|---|
| ``string.concat (값) (값) ...`` | 값들을 문자열로 바꿔서 이어붙입니다. ``null``은 빈 문자열이 됩니다. |
| ``string.join (구분자) (값) (값) ...`` | 값들을 구분자로 이어붙입니다. 값이 배열/리스트 하나라면 그 원소들을 이어붙입니다. |
| ``string.format (형식) (값) (값) ...`` | C#의 ``string.Format``처럼 ``{0}``, ``{1:F2}``, ``{0,5}`` 자리에 값을 넣습니다. ``{0}``이 첫번째 값입니다. (``console.write``와 달리 형식 문자열은 세지 않음) |
| ``string.compare (a) (b)`` | 유니코드 순서로 비교해서 a가 앞이면 ``-1``, 같으면 ``0``, 뒤면 ``1``을 반환합니다. ``null``은 가장 앞입니다. |
| ``string.equals (a) (b)`` / ``string.equals (a) (b) true`` | 두 문자열이 같은지 비교합니다. 세번째 인자가 참이라면 대소문자를 무시합니다. |
| ``string.isnullorempty (값)`` | 값이 ``null`` 또는 빈 문자열이라면 ``true``를 반환합니다. |
| ``string.isnullorwhitespace (값)`` | 값이 ``null``이거나 공백 문자로만 이루어졌다면 ``true``를 반환합니다. |
| ``string.indexof (문자열) (찾을 문자열)`` / ``... (시작)`` | 찾을 문자열이 처음 나오는 인덱스를 반환합니다. 없다면 ``-1``입니다. 시작 인덱스부터 찾을수도 있습니다. |
| ``string.lastindexof (문자열) (찾을 문자열)`` | 찾을 문자열이 마지막으로 나오는 인덱스를 반환합니다. 없다면 ``-1``입니다. |
| ``string.contains (문자열) (찾을 문자열)`` | 찾을 문자열이 있다면 ``true``를 반환합니다. |
| ``string.startswith (문자열) (값)`` / ``string.endswith (문자열) (값)`` | 값으로 시작하는지/끝나는지 검사합니다. |
| ``string.replace (문자열) (바꿀 문자열) (새 문자열)`` | 바꿀 문자열을 모두 새 문자열로 바꿉니다. 새 문자열이 ``null``이라면 제거합니다. |
| ``string.substring (문자열) (시작)`` / ``... (시작) (길이)`` | 시작 인덱스부터 길이만큼(생략하면 끝까지)의 문자열을 반환합니다. |
| ``string.insert (문자열) (인덱스) (값)`` | 인덱스 위치에 값을 끼워넣은 문자열을 반환합니다. |
| ``string.remove (문자열) (시작)`` / ``... (시작) (개수)`` | 시작 인덱스부터 개수만큼(생략하면 끝까지)의 글자를 제거한 문자열을 반환합니다. |
| ``string.toupper (문자열)`` / ``string.tolower (문자열)`` | 대문자/소문자로 바꾼 문자열을 반환합니다. |
| ``string.trim (문자열)`` / ``string.trimstart`` / ``string.trimend`` | 양쪽/앞쪽/뒤쪽의 공백 문자를 제거합니다. 두번째 인자로 문자열을 넣으면 그 문자열에 있는 글자들을 제거합니다. (``string.trim 'xxhixx' 'x'``는 ``'hi'``) |
| ``string.padleft (문자열) (길이)`` / ``string.padright`` / ``... (글자)`` | 길이가 될때까지 앞쪽/뒤쪽에 글자(생략하면 공백)를 채웁니다. (``string.padleft '7' 3 '0'``은 ``'007'``) |
| ``string.split (문자열) (구분자)`` / ``string.split (문자열)`` | 구분자로 나눈 문자열 배열을 반환합니다. (``div``와 같음) 구분자를 생략하면 공백 문자마다 나눕니다. |
| ``string.tochararray (문자열)`` | 한 글자씩 나눈 문자열 배열을 반환합니다. |
| ``string.charcode (문자열)`` / ``... (인덱스)`` | 인덱스(생략하면 0) 위치 글자의 UTF-16 코드를 정수로 반환합니다. (``string.charcode 'A'``는 ``65``) |
| ``string.fromcharcode (코드) (코드) ...`` | UTF-16 코드(0 ~ 65535)들로 문자열을 만듭니다. (``string.fromcharcode 72 105``는 ``'Hi'``) |

```
name = '  Jyunni  '
name = string.trim name
console.writeline (string.format 'Hello, {0}! ({1}글자)' (string.toupper name) (length name))
console.writeline (string.join ', ' (string.split 'c b a' ' '))
```
위 코드는 ``Hello, JYUNNI! (6글자)``, ``c, b, a`` 순서로 출력합니다.

## 비교/논리 연산
### less, greater
``less a b``는 C 계열 언어의 ``a < b``, ``greater a b``는 ``a > b``와 같습니다.  
인자가 셋 이상이라면 이웃한 인자끼리 모두 비교합니다. 즉 ``less 1 2 3``은 ``1 < 2 && 2 < 3``(오름차순인지), ``greater 3 2 1``은 ``3 > 2 && 2 > 1``(내림차순인지)과 같습니다.  
같은 값이 이웃해 있다면 false입니다. (``less 1 1 2``는 false) 인자가 하나뿐이라면 항상 true입니다.
```
console.writeline (less 1 2 3)
console.writeline (greater "가" "나" "다" "라")
```
위 코드는 ``True``, ``False`` 순서로 출력합니다.

숫자끼리는 값으로 비교하며(정수와 실수를 섞어도 됩니다), 문자열끼리는 유니코드 순서로 비교합니다. (``less 'B' 'a'``는 true)  
숫자와 문자열처럼 크기를 비교할수 없는 값이 섞여 있다면 오류가 발생합니다. ``math.nan``과의 비교는 항상 false입니다.
### and, or, not
인자가 모두 정수라면 비트 연산을 합니다. ``and 10 20 30``은 C 계열 언어의 ``10 & 20 & 30``, ``or 1 2 4``는 ``1 | 2 | 4``, ``not 5``는 ``~5``와 같습니다.  
정수가 아닌 값이 하나라도 있다면 논리 연산을 하고 ``true``/``false``를 반환합니다. ``and a b c``는 ``a && b && c``, ``or a b c``는 ``a || b || c``, ``not a``는 ``!a``와 같습니다. (참/거짓 판단 기준은 ``if``와 같습니다.)  
``not``은 첫번째 인자만 사용하고, 두번째 인자부터는 무시합니다.
```
if (and (greater x 0) (less x 10))
	console.writeline "x는 한 자리 자연수입니다."
end
```
주의: 다른 함수와 마찬가지로 인자를 모두 계산한 뒤에 연산하므로, C 계열 언어처럼 계산을 생략(단락 평가)하지 않습니다. 단락 평가가 필요하다면 1.6.0부터 ``&&``, ``||`` [연산자](#연산자-160부터)를 사용하세요.  
또한 정수에 ``not``을 쓰면 비트 반전이 되므로 ``not 1``은 ``-2``(참)입니다. 정수가 0인지 검사하려면 ``equal x 0`` 또는 ``not (bool x)``를 사용하세요.
## 연산자 (1.6.0부터)
C 계열 언어의 연산자를 쓸수 있습니다.
```
x = (1 + 2) * 3
if x >= 9 && x % 3 == 0
	console.writeline "x는 9 이상인 3의 배수입니다."
end
```
### 연산자 목록과 우선순위
우선순위는 C#과 같으며, 위에 있는 연산자부터 먼저 계산합니다. 같은 줄의 연산자는 왼쪽부터 묶습니다. (``??``와 ``? :``는 오른쪽부터)

| 우선순위 | 연산자 | 같은 계산 |
|---|---|---|
| 1 | 함수 호출 ``(함수명) (인자1) (인자2) ...`` | |
| 2 | ``+x`` ``-x`` ``!x`` ``~x`` | ``!x``는 논리 부정(``not (bool x)``), ``~x``는 정수의 비트 반전 |
| 3 | ``*`` ``/`` ``%`` | ``mul``, ``div``, ``mod`` |
| 4 | ``+`` ``-`` | ``add``, ``sub`` |
| 5 | ``<<`` ``>>`` | 정수의 비트 이동 (C#처럼 이동할 칸 수는 0~63으로 자름) |
| 6 | ``<`` ``>`` ``<=`` ``>=`` | ``less``, ``greater`` |
| 7 | ``==`` ``!=`` | ``equal``, ``not (equal a b)`` |
| 8 | ``&`` | ``and`` (정수끼리는 비트 AND, 그 외에는 논리 AND) |
| 9 | ``^`` | 정수끼리는 비트 XOR, 그 외에는 참/거짓이 다른지 |
| 10 | ``\|`` | ``or`` (정수끼리는 비트 OR, 그 외에는 논리 OR) |
| 11 | ``&&`` | 논리 AND (단락 평가) |
| 12 | ``\|\|`` | 논리 OR (단락 평가) |
| 13 | ``??`` | 왼쪽 값이 ``null``이 아니면 왼쪽 값, ``null``이면 오른쪽 값 (단락 평가) |
| 14 | ``조건 ? 참일때 : 거짓일때`` | 조건 연산자 (단락 평가) |

산술/비교 연산자는 같은 계산의 내장 함수와 결과와 오류가 같습니다. 예를 들어 ``'a' + 1``은 ``'a1'``, ``'ab' * 2``는 ``'abab'``, ``(list 1 2) + 3``은 ``add``처럼 원소를 이어붙인 새 리스트, ``1 / 0``은 ``0으로 나눌수 없습니다`` 오류입니다.  
비교 연산자는 ``math.nan``과 비교하면 ``!=`` 이외에는 항상 ``false``입니다.  
``&&``, ``||``, ``!``는 ``if``와 같은 기준으로 참/거짓을 판단하고 ``true``/``false``를 반환합니다. (``not 1``은 ``-2``지만 ``!1``은 ``false``)

연산자는 ``add``, ``sub`` 같은 함수가 아닌 **특수 키워드**입니다. 이름이 아니므로 대입하거나(``+ = 1``) 삭제할수(``+ =``) 없고, 스크립트가 ``add``를 다시 정의하거나 삭제해도 ``+``의 계산은 바뀌지 않습니다.
### 함수 호출이 먼저 묶임
함수 호출(함수 이름과 그 뒤의 인자들)은 모든 연산자보다 먼저 묶입니다. 인자는 지금까지처럼 상수, 이름, 괄호 하나씩이며, 연산자를 만나면 인자가 끝납니다.
```
func twice
	param n
	return n * 2
endfunc
console.writeline (twice 3 + 1)      // (twice 3) + 1 = 7
console.writeline (twice (3 + 1))    // twice 4 = 8
x = twice 3 + twice 4                // (twice 3) + (twice 4) = 14
```
그래서 연산자 식을 함수의 인자로 넘기려면 **괄호로 감싸야** 합니다. ``console.writeline a + b``는 ``a``를 출력한 결과(``null``)에 ``b``를 더하는 식입니다. ``console.writeline (a + b)``로 쓰세요.

음수 상수와 뺄셈은 띄어쓰기로 구별합니다. 값 바로 뒤에 붙은 ``-``(``x-1``)와 띄어 쓴 ``-``(``x - 1``)는 뺄셈이고, 앞이 띄어져 있고 뒤에 숫자가 붙은 ``-``(``-1``)는 음수 상수입니다. 따라서 ``point -5 4``는 ``point``에 ``-5``와 ``4``를 넘기고, ``x -1``은 ``x`` 다음에 인자 ``-1``이 있는 식이므로 뺄셈이 아닙니다.
### 키워드의 인자
``if``, ``while``, ``repeat``, ``return``, ``goto``, ``for``의 인자도 연산자 식을 쓸수 있으며, 식 맨 앞의 이름은 함수 호출입니다.
```
while i < length l
	i += 1
end
return point (x + 1) y
for x array.range 3
	console.writeline x
end
```
1.5.3까지는 키워드 다음의 이름은 변수의 값만 읽었습니다. 1.6.0부터는 ``return f``가 함수 ``f``를 호출하고, ``return l 0``이 리스트 ``l``의 0번째 원소를 반환합니다. (``return a (b)``처럼 변수 뒤에 인자를 쓰면, 줄 맨 앞에서 변수 뒤에 인자를 쓴 것과 같이 인자는 계산하지 않습니다)
### 단락 평가
``&&``, ``||``, ``??``, ``? :``는 필요한 쪽만 계산합니다.
```
if i < length l && (l i) > 0
	console.writeline "양수"
end
name = input ?? "이름 없음"
console.writeline (score >= 60 ? "합격" : "불합격")
```
### 복합 대입
``+=``, ``-=``, ``*=``, ``/=``, ``%=``, ``&=``, ``|=``, ``^=``, ``<<=``, ``>>=``, ``??=``를 쓸수 있습니다. ``x += 1``은 ``x = x + 1``과 같으며, 이미 있는 변수에만 쓸수 있습니다. (구조체 필드 ``p.x += 1``도 가능)
### 구조체의 연산자 다시 정의 (오버로딩)
구조체 안에서 ``func (연산자)``로 그 구조체 값의 연산자를 다시 정의할수 있습니다.
```
struct point
	param x
	param y
	func +
		param other
		return point (x + other.x) (y + other.y)
	endfunc
endstruct

p1 = point 10 20
p2 = point -5 4
if p1 + p2 == (add p1 p2)
	console.write "success"
end
```
- ``a (연산자) b``는 왼쪽 값 ``a``의 연산자 함수를 ``b``를 인자로 호출한 결과입니다. 단항 연산자(``-a``, ``!a``, ``~a``, ``+a``)는 인자 없이 호출합니다. (``param``은 ``null``)
- 연산자 함수는 왼쪽 값의 **복사본**에서 실행되므로, 함수 안에서 필드를 바꿔도 원래 값은 바뀌지 않습니다.
- 다시 정의할수 있는 연산자: ``+`` ``-`` ``*`` ``/`` ``%`` ``==`` ``!=`` ``<`` ``>`` ``<=`` ``>=`` ``&`` ``|`` ``^`` ``<<`` ``>>`` ``!`` ``~`` (``&&``, ``||``, ``??``, ``? :``, 대입은 다시 정의할수 없습니다)
- ``func (연산자)``는 ``struct`` 안에서만 쓸수 있습니다. (구조체 함수 안이나 스크립트 최상위에서는 오류)
- 비교 연산자는 정의하지 않았다면 다른 비교 연산자에서 이끌어냅니다: ``a != b``는 ``!(a == b)``, ``a > b``는 ``b < a``, ``a <= b``는 ``!(a > b)``, ``a >= b``는 ``!(a < b)``. 따라서 ``==``와 ``<``만 정의해도 모든 비교 연산자를 쓸수 있습니다.
- 같은 계산의 내장 함수도 다시 정의한 연산자를 사용합니다: ``add``(``+``), ``sub``(``-``), ``mul``(``*``), ``div``(``/``), ``mod``(``%``), ``and``(``&``), ``or``(``|``), ``not``(``!``), ``equal``(``==``), ``less``(``<``), ``greater``(``>``). ``equal``/``less``와 같은 기준으로 비교하는 ``array.sort``, ``array.contains``, ``array.indexof``, ``array.min`` 등도 마찬가지입니다.
- 다시 정의하지 않은 연산자는 원래대로 계산합니다. (``==``는 필드를 비교, ``+``는 ``add``와 같은 오류)
- ``==``를 다시 정의했다면 ``a == null``도 그 함수를 호출합니다. 값이 ``null``인지 확인하려면 왼쪽에 ``null``을 쓰세요. (``null == o``는 왼쪽 값이 구조체가 아니므로 원래대로 비교)
```
func ==
	param other
	if null == other
		return false
	end
	return x == other.x && y == other.y
endfunc
```
## 팁
### 삭제 연산
사실 Jyuno에서 삭제 연산이 별로 필요하지 않습니다. 삭제 연산 없이도 충분히 원하는 스크립트를 작성할수 있습니다.<br>
또한, 함수에서 리턴할 경우, 함수 내에서 만들어진 지역 변수는 모두 삭제됩니다.<br>
그렇기에 일관성 있는 코드 작성을 위해서는, 삭제 연산을 삼가하시길 바랍니다.

## 명령어(command)
아래 명령어는 모든 Jyuno 인터프리터가 지원하지 않습니다.<br>
Jyuno를 사용하는 C# 프로그램이 일부 Jyuno 명령어를 비활성화 할수 있기 때문에, 해당 프로그램이 어느 Jyuno 명령어를 지원하는지 확인해야 합니다.
### 기본
<b>아래 명령어는 Jyuno에서 기본적으로 포함되며, 반드시 지원합니다.</b>
- 정수: ``int`` (0을 반환) 또는 ``int (any)`` (다른 타입의 값을 int로 변환합니다.)
- 실수: ``double`` (0.0 을 반환) 또는 ``double (any)`` (다른 타입의 값을 double로 변환합니다.)
- 문자열: ``string`` (빈 문자열을 반환) 또는 ``string (any)`` (다른 타입의 값을 string으로 변환합니다.)
- 덧셈: ``add (any) (any) (any) ...`` (개수에 상관없이 주어진 인자를 모두 더함) 또는 ``add (array|list) (any) ...`` (배열/리스트를 이어붙임)
- 뺄셈: ``sub (int|double) (int|double)`` 또는 ``sub (string) (string)`` (문자열에 원하는 문자열을 제거함) 또는 ``sub (array|list) (any)`` (차집합)
- 곱셈: ``mul (int|double) (int|double) ...`` (개수에 상관없이 주어진 인자를 모두 곱함) 또는 ``mul (string) (int)`` (문자열을 원하는 횟수로 반복함)
- 나눗셈: ``div (int|double) (int|double)`` 또는 ``div (string) (string)`` (문자열을 구분자로 나눈 문자열 배열)
- 나머지: ``mod (int|double) (int|double)``
- 배열: ``array (any) (any) ...`` (주어진 인자를 원소로 하는 배열)
- 리스트: ``list (any) (any) ...`` (주어진 인자를 원소로 하는 리스트)
- 길이: ``length (string|array|list)`` (문자열의 글자 수, 또는 배열/리스트의 원소 개수)
- 컬렉션: ``array.sort``, ``array.reverse``, ``array.shuffle``, ``array.contains``, ``array.indexof``, ``array.slice``, ``array.join``, ``array.new``, ``array.copy``, ``array.lastindexof``, ``array.count``, ``array.distinct``, ``array.binary_search``, ``array.fill``, ``array.min``, ``array.max``, ``array.sum``, ``array.range`` (``list.``로 시작하는 같은 이름의 함수도 있음), ``list.push``, ``list.pop``, ``list.insert``, ``list.removeat``, ``list.remove``, ``list.clear`` ([컬렉션 함수](#컬렉션-함수-array-list) 참고)
- 문자열: ``string.concat``, ``string.join``, ``string.format``, ``string.indexof``, ``string.replace``, ``string.substring``, ``string.trim``, ``string.split`` 등 ([문자열 함수](#문자열-함수-string) 참고)
- 비교: ``equal (any) (any) ...`` (개수에 상관없이 주어진 모든 인자를 비교합니다. 모두 동일하면 true, 하나라도 서로 다를경우 false를 반환합니다.) 
- 작다: ``less (int|double|string) (int|double|string) ...`` (앞의 값이 뒤의 값보다 작으면 true. 인자가 셋 이상이라면 모든 인자가 오름차순인지 검사합니다.)
- 크다: ``greater (int|double|string) (int|double|string) ...`` (앞의 값이 뒤의 값보다 크면 true. 인자가 셋 이상이라면 모든 인자가 내림차순인지 검사합니다.)
- 그리고: ``and (any) (any) ...`` (인자가 모두 정수라면 비트 AND, 그렇지 않으면 논리 AND)
- 또는: ``or (any) (any) ...`` (인자가 모두 정수라면 비트 OR, 그렇지 않으면 논리 OR)
- 부정: ``not (any)`` (정수라면 비트 NOT, 그렇지 않으면 논리 NOT)
- null(상수): ``null``
- true(상수): ``true``
- false(상수): ``false``
### 콘솔(Console)
콘솔과 관련된 명령어입니다.
- 출력: ``console.write (any)`` 또는 ``console.write (string) (any) (any)``
   (console.write는 C#의 Console.Write 함수를 그대로 사용합니다. 그에따라 ``console.write "hello {1}" 'jyunni'`` 같은 명령어를 사용할수 있습니다.)
- 입력: ``console.readline``
- 초기화: ``console.clear``
- 제목(변수): ``console.title = (string)``
### 수학(Math)
수학과 관련된 명령어입니다.
- 절댓값: ``math.abs (int|double)``
- 사인: ``math.sin (double)``
- 코사인: ``math.cos (double)``
- 탄젠트: ``math.tan (double)``
- 제곱: ``math.pow (double) (double)``
- 로그 (상용로그): ``math.log (double)``
- 로그 (이진로그): ``math.log2 (double)``
- 파이 (상수): ``math.pi``
- 난수 (빠름): ``math.random`` (0 이상 1 미만의 실수) 또는 ``math.random (max)`` 또는 ``math.random (min) (max)``
- 난수 (안전함): ``math.csprng`` (인자 규칙은 ``math.random``과 같음)

``math.random``과 ``math.csprng``는 ``min`` 이상 ``max`` 미만의 값을 무작위로 뽑습니다. (``max``만 넣으면 ``min``은 0)  
인자가 모두 정수라면 정수를, 실수가 하나라도 있다면 실수를 뽑습니다. 예를 들어 ``math.random 1 7``은 주사위처럼 1~6 중 하나를 뽑고, ``math.random 1.0 7``은 1 이상 7 미만의 실수를 뽑습니다.  
``min``이 ``max``보다 작지 않다면 오류가 발생합니다.  
``math.random``은 빠르지만 다음 값을 예측할수 있으므로, 비밀번호나 토큰처럼 보안이 필요한 값은 운영체제의 암호학적으로 안전한 난수 생성기(C#의 ``RandomNumberGenerator``)를 쓰는 ``math.csprng``로 뽑으세요.  
### 파일(File)
파일과 관련된 명령어입니다.
- 파일 존재 여부: ``file.exist (string)``
- 디렉토리 존재 여부: ``directory.exist (string)``
